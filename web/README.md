# TopBand BMS Gateway — Web UI

Source files for the browser dashboard, bundled into firmware as `littlefs_ui.tar.gz`.

## Structure

```
web/
  ui/                  Source files — edit these
    index.html         Single-page application shell
    style.css          All styles (CSS custom properties, dark/light theme)
    app.js             Routing, polling, DOM updates
    favicon.svg        Browser tab icon
    ui_version.txt     Auto-generated by build script; do not edit
  build_ui.sh          Manual build trigger (wraps the Python script)
  build_ui.py          PlatformIO pre-build hook (runs automatically on pio run)
  littlefs_ui.tar.gz   Generated bundle — .gitignored, recreated on every build
```

## Building

The tarball is generated automatically before every `pio run`.
To build manually (e.g. to check bundle size):

```sh
bash web/build_ui.sh
```

## Local Development Workflow

Point the browser directly at the device IP while editing:

1. Flash firmware: `pio run -e esp32s3 -t upload`
2. Find device IP from serial log: `pio device monitor`
3. Open `http://<device-ip>/` in browser — live BMS data polls every 2 s
4. Edit `web/ui/` files locally
5. Re-run `pio run -e esp32s3 -t upload` to flash updated UI bundle

Alternatively, proxy API calls from a local static server:

```sh
# Serve local UI files and forward /api/* to the device.
# Python simple proxy example (replace <device-ip>):
python3 - <<'EOF'
import http.server, urllib.request, os

DEVICE = "http://192.168.1.x"

class H(http.server.SimpleHTTPRequestHandler):
    def __init__(self, *a, **kw):
        super().__init__(*a, directory="web/ui", **kw)
    def do_GET(self):
        if self.path.startswith("/api") or self.path.startswith("/favicon"):
            r = urllib.request.urlopen(DEVICE + self.path)
            self.send_response(200)
            self.send_header("Content-Type", r.headers["Content-Type"])
            self.end_headers()
            self.wfile.write(r.read())
        else:
            super().do_GET()

http.server.HTTPServer(("", 8080), H).serve_forever()
EOF
# Open http://localhost:8080/
```

## UI Version Bumping

When you make UI changes, bump `UI_VERSION` in [src/storage/ui_provisioner.h](../src/storage/ui_provisioner.h):

```cpp
constexpr const char* UI_VERSION = "f-mvp-2";  // increment here
```

The next firmware flash extracts the new bundle and writes the new version marker.
A boot with a matching version string is a no-op (no extraction).
